## Important project boundary

The provided app is a front-end internship demonstration with a mock JSON Server. It does not implement production authentication, real GPS, live driver telemetry, secure role-based access, or legally valid proof-of-delivery signatures. Those would require a secured backend, authorised data, and additional testing. Do not present the demo as a production freight platform.
